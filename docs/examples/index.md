# Examples

Each example is an interactive walkthrough — a purpose-built agent, the
conversation, and what happens on disk. For *scheduled, unattended* work,
you want the [Cookbook](../cookbook/index.md) instead: those are
copy-pasteable `WORKFLOW.md` recipes.

- [Deep Research & Obsidian](./deep-research.md) — multi-source research filed into your vault
- [PDF Summary](./pdf-summary.md) — read a local PDF and summarize it
- [Git History Squash](./git-squash.md) — analyze and squash history
- [PR Descriptions](./pr-description.md) — generate a PR body from the diff
- [Security Scan & Auto-Fix](./security-scan.md) — find and fix vulnerabilities
- [Dependency Audit](./dependency-audit.md) — audit and safely upgrade dependencies
- [Project Onboarding](./project-onboarding.md) — clone a repo and run its README end to end
- [Cross-Repo Refactoring](./cross-repo-refactoring.md) — one refactor across many repos
- [Bulk Email Cleanup](./bulk-email-cleanup.md) — clean up old automated email
- [Weekly Security Audit](./security-audit.md) — scheduled CVE briefing
- [Investment Analysis](./investment.md) — weekly market report
- [Meeting Assistant](./meetings.md) — pre-meeting brief and minutes
- [API Integration Generator](./api-integration-generator.md) — research an API, generate the client
- [Deployment Pipeline](./deployment-pipeline.md) — deploys with pre-checks and smoke tests
- [Cost Optimizer](./cost-optimizer.md) — analyze cloud spend
