# User Guides

Learn how to use Jazz effectively.

## Getting Started

- [Quick Start](./quick-start.md): Install and run your first agent.
- [Creating Agents](./creating-agents.md): Build custom agents tailored to your needs.
- [Airgapped & Self-Hosted](./airgapped.md): Run Jazz fully offline with Ollama or llama.cpp.
- [Observability](./observability.md): Send run telemetry to your own OpenTelemetry collector or Langfuse.

## End-to-End Use Cases

Discover what's possible with Jazz through practical examples:

- **[Deep Research & Obsidian](./use-cases/deep-research.md)**: Conduct deep searches and save reports to your Obsidian vault.
- **[Weekly Security Audit](./use-cases/security-audit.md)**: Automate security checks and receive weekly briefings.
- **[Investment Analysis](./use-cases/investment.md)**: Get weekly market reports and investment insights.
- **[Meeting Assistant](./use-cases/meetings.md)**: Prepare for meetings and generate smart minutes.
- **[Security Scan & Auto-Fix](./use-cases/security-scan.md)**: Scan a codebase for vulnerabilities and fix the critical ones.
- **[Dependency Audit](./use-cases/dependency-audit.md)**: Audit project dependencies and safely fix vulnerabilities.
- **[PDF Summary](./use-cases/pdf-summary.md)**: Read PDF documents and generate comprehensive summaries.
- **[Bulk Email Cleanup](./use-cases/bulk-email-cleanup.md)**: Clean up thousands of old emails by age, sender, or content.
- **[Git Commit & Push](./use-cases/git-commit-push.md)**: Commit with intelligent messages and push in one ask.
- **[Git History Squash](./use-cases/git-squash.md)**: Analyze history and squash related or useless commits.
- **[PR Descriptions](./use-cases/pr-description.md)**: Generate detailed PR descriptions from changes and history.
- **[Project Onboarding](./use-cases/project-onboarding.md)**: Clone a repo and run its README setup end to end.
- **[Cross-Repo Refactoring](./use-cases/cross-repo-refactoring.md)**: Apply a refactor across multiple repositories.
- **[API Integration Generator](./use-cases/api-integration-generator.md)**: Research an API and generate the integration code.
- **[Deployment Pipeline](./use-cases/deployment-pipeline.md)**: Coordinate deployments with pre-checks, migrations, and smoke tests.
- **[Cost Optimizer](./use-cases/cost-optimizer.md)**: Analyze cloud infrastructure usage and suggest savings.
