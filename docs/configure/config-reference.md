# Config file reference

Every setting `~/.jazz/config.json` (or a project's `./.jazz/config.json`) accepts. The table
is generated from the schema Jazz validates config files against, so a key missing here is a
key Jazz rejects: `jazz config validate` names it and suggests the closest real one.

- **Key** is the dotted path `jazz config get` and `jazz config set` take. `<provider>`,
  `<model>`, `<server>` and `<header>` stand for a name you choose or a member of a family;
  `[]` marks a list whose entries each have these fields.
- **Accepts** is what the value must be, in the words `jazz config validate` uses.
- **Secret** keys belong in the keyring. `jazz config set` stores them there when one is
  available, and falls back to the protected secrets file otherwise. Environment variables for
  the same secrets are listed in [Environment variables](./environment-variables.md).

[Jazz configuration](./jazz.md) explains how global and project files merge, and the
[agent file](./agents.md) has its own keys.
